# ExpandedDimensions
This is a C# Windows Presentation Foundation (WPF) application for creating 3D models

It aims to follow SOLID principles and implement at least 3 Design Patterns

## Structure
The organization of this project will use the MVC Structure:
- Models: Contains the data that will represent objects
- Views: Contains the information to display the data
- Controllers: Contains the logic to manage the data in the application

The Design Patterns used will have at least one from the following categories:
- Creational
- Structural
- Behavioral

The current planned patterns are: Builder, Flyweight, and Command
- Builder: allows for defining steps to create an object, which will be crucial for a creational application
- Flyweight: allows for objects with repeatable behavior, which will support consistent creation
- Command: allows for user input to dictate the output through a set of actions, which will allow control over the creation
